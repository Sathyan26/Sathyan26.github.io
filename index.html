Featured

RAG-Based AI Customer Support Application

A full production-style Retrieval-Augmented Generation assistant — one cohesive pipeline from ingestion to generation, not standalone scripts. A pluggable provider architecture (Strategy pattern) gives both embeddings and generation three interchangeable tiers — OpenAI → local model → offline fallback — with an auto mode that degrades gracefully, so the whole app runs end-to-end with zero API keys.

Storage runs on PostgreSQL + pgvector with SQLAlchemy 2.0 and Alembic migrations, HNSW-indexed for cosine-similarity search. A custom cleaning pipeline (HTML/Unicode normalization, content-hash dedup, sentence-aware chunking) processed a noisy support knowledge base. Exposed via FastAPI (/chat /ingest /documents /health) plus a Typer CLI and Streamlit frontend, every answer returns cited source passages. Full stack runs in Docker Compose with a GitHub Actions CI pipeline against a live Postgres service container.
