AI Customer Support Application

A full production-style RAG pipeline built end to end — ingestion → pgvector storage → retrieval → generation — with a pluggable provider architecture (OpenAI → local model → offline fallback), so the app runs fully with zero API keys.

Storage runs on PostgreSQL + pgvector with SQLAlchemy 2.0 and Alembic migrations, HNSW-indexed for cosine-similarity search. Exposed through a FastAPI service, a Typer CLI, and a Streamlit frontend, with Docker Compose and GitHub Actions CI. Every answer returns cited source passages.
